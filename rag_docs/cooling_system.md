# Synthetic Vehicle Service Guide — Cooling System

IMPORTANT: Synthetic educational content; not an OEM manual.

## Temperature guidance
- 85–105°C: normal operating range
- 105–110°C: warning zone
- Above 110°C: overheating condition requiring prompt investigation

## Possible causes
- Low coolant
- Coolant leak
- Thermostat malfunction
- Cooling fan failure
- Radiator restriction
- Water-pump degradation
- Temperature-sensor fault

## Diagnostic sequence
1. Verify coolant level when safe.
2. Check for visible leaks.
3. Check fan operation.
4. Inspect thermostat behavior.
5. Inspect radiator airflow/restriction.
6. Check water-pump performance.
7. Validate temperature-sensor readings.

## Predictive signal
A gradual temperature increase over several trips is more significant than a single spike, especially when accompanied by reduced oil pressure or increased vibration.
